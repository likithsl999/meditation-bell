# Audio Assets

Place three MP3 files in this folder before building:

| Filename           | Description                              |
|--------------------|------------------------------------------|
| `temple_bell.mp3`  | A single deep temple bell strike         |
| `singing_bowl.mp3` | A resonant Tibetan singing bowl tone     |
| `soft_chime.mp3`   | A gentle soft wind-chime sound           |

## Where to find free sounds

- https://freesound.org — search "temple bell", "singing bowl", "meditation chime"
- https://pixabay.com/music — filter by "Meditation" or "Ambience"

All files must be named exactly as listed above (lowercase, underscores). MP3 format, mono or stereo, any bitrate.

## Why the app ships without sounds

Audio files cannot be generated by code and must be sourced separately due to copyright. The app will log a non-fatal error and silently skip the bell if the file is missing, so the timer still works correctly during development.
